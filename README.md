# NovaTec - E-commerce

## Sobre o projeto

O **NovaTec** é um projeto individual desenvolvido para integrar as disciplinas de Front-end e Programação Web.

A aplicação consiste em um e-commerce de produtos de tecnologia.

O Front-end foi desenvolvido utilizando **React** e o Back-end utilizando **Java, Spring Boot e JdbcTemplate**, com persistência dos produtos em um banco de dados relacional.

---

## Tecnologias utilizadas

### Front-end

- React
- Vite
- JavaScript
- CSS Modules

### Back-end

- Java
- Spring Boot
- JdbcTemplate

### Banco de dados

- H2
- SQL

---

## Produto

Cada produto possui os seguintes campos:

| Campo | Tipo |
|---|---|
| id | Integer |
| nome | String |
| descricao | String |
| preco | Double |
| categoria | String |
| quantidade | Integer |
| imagem | String |

O `id` é gerado automaticamente pelo banco de dados.

---

## Banco de dados

Tabela utilizada para armazenar os produtos:

```sql
CREATE TABLE IF NOT EXISTS produto (
    id INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    descricao VARCHAR(250) NOT NULL,
    preco DECIMAL(10, 2),
    categoria VARCHAR(50) NOT NULL,
    quantidade INT,
    imagem VARCHAR(700) NOT NULL
);
API

URL base:

http://localhost:8080/produtos
Cadastrar produto
Método
POST /produtos
Exemplo de requisição
{
  "nome": "Teclado Mecânico",
  "descricao": "Teclado mecânico RGB",
  "preco": 249.90,
  "categoria": "Periféricos",
  "quantidade": 10,
  "imagem": "teclado.png"
}
Resposta

Status:

201 Created

Exemplo:

{
  "id": 1,
  "nome": "Teclado Mecânico",
  "descricao": "Teclado mecânico RGB",
  "preco": 249.90,
  "categoria": "Periféricos",
  "quantidade": 10,
  "imagem": "teclado.png"
}
Listar produtos
Método
GET /produtos
Resposta

Status:

200 OK

Exemplo:

[
  {
    "id": 1,
    "nome": "Teclado Mecânico",
    "descricao": "Teclado mecânico RGB",
    "preco": 249.90,
    "categoria": "Periféricos",

Caso nenhum produto esteja cadastrado:

Método	Endpoint	Função	Status
POST	/produtos	Cadastrar produto	201
GET	/produtos	Listar produtos	200
CORS

O Back-end permite requisições do Front-end executado em:

http://localhost:5173

Configuração utilizada:

@CrossOrigin(origins = "http://localhost:5173")
Como executar
Front-end
cd Frontend
npm install
npm run dev

O Front-end será executado em:

http://localhost:5173
Back-end

Execute o projeto Spring Boot pela IDE.

A API estará disponível em:

http://localhost:8080
Validações

O endpoint de cadastro será responsável por validar os dados antes de salvar o produto no banco.

Entre as validações estão:

Nome obrigatório;
Descrição obrigatória;
Preço maior que zero;
Categoria obrigatória;
Quantidade não negativa;


Quando os dados forem inválidos, a API deverá retornar:

400 Bad Request

Além disso, se é o usuário tentar cadastrar um produto que o nome e descrição 
já tem registro no Banco de dados, sofrerá a validação com:

409 (Conflict)
